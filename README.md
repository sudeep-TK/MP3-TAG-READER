# MP3 Tag Reader

A C-based MP3 Tag Reader application developed to read, display, and modify MP3 metadata.

## Project Overview

The MP3 Tag Reader is a command-line application developed in C to work with metadata stored in MP3 files. The project implements operations for viewing and displaying tag information and modifying the required metadata.

The project is organized into modular functions, including helper functions, to make the code structured and easier to maintain.

## Operations

### 1. View
- Reads the MP3 file and retrieves the available tag information.
- Displays the metadata stored in the MP3 file.

### 2. Display
- Displays the extracted MP3 tag information in a user-readable format.
- Shows the available metadata fields from the MP3 file.

### 3. Modify
- Allows the user to modify the required MP3 tag information.
- Updates the selected metadata in the MP3 file.

### 4. Helper Functions
- Provides supporting functions required for reading, displaying, and modifying MP3 tag information.
- Handles common file and data-processing operations used by the main functions.
